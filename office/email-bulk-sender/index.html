批量邮件模板工具使用说明

批量邮件模板工具是一款纯前端在线工具，提供面试邀请、入职通知、会议通知、生日祝福、放假通知等 6 类中文办公邮件模板，支持变量替换、实时 HTML 预览、草稿本地保存，并可导出 .eml 或复制 HTML。 你的配置和邮件内容保存在你的浏览器，不真正发送邮件。

1. 服务配置

在「服务配置」区选择你的 SMTP 服务商（163邮箱 / QQ邮箱 / 腾讯企业邮箱 / 阿里云邮箱 / 139邮箱）， 并填写发件昵称、发件邮箱账号与授权码。这些信息仅用于提示你准备发信所需的资料， 工具不会连接 SMTP，也不会上传你的配置和邮件内容到服务器。

2. 模板选择

从模板下拉框中选择「自定义文案 / 面试邀请 / 入职通知 / 会议通知 / 生日祝福 / 放假通知」， 选中后系统会自动把该模板的主题与正文填入下方表单，你可以继续修改。

3. 邮件内容与预览

填写批量收件人（多个地址用英文逗号分隔）、邮件主题与正文。正文中可使用 {{姓名}}、 {{公司}} 等占位符。 在「变量填充」区填入对应值后，点击「邮件预览」，即可通过 iframe 看到渲染后的完整 HTML 邮件。

4. 导出与复制（纯前端替代）

本工具为纯前端版本，不真正发信。点击「导出 .eml」可下载一个标准 .eml 文件 （含 From/To/Subject 与 Base64 编码的 HTML 正文），用 Outlook、Foxmail 等邮件客户端打开即可发送； 点击「复制 HTML」可把渲染后的 HTML 复制到剪贴板，方便粘贴到其它编辑器或邮件系统。

5. 草稿保存

服务商、授权码、账号、昵称、模板、收件人、主题、正文会全量自动保存到本地浏览器， 下次打开自动恢复。你也可以随时点击「保存草稿」手动保存。清空浏览器数据或换设备后草稿不会保留。

6. 清空数据

点击「清空数据」会一键清空表单并删除对应的本地存储键，方便重新填写或保护隐私。

常见问题

这个工具能直接群发邮件吗？

不能。本工具是纯前端版本，浏览器静态站无法连接 SMTP，因此不真正发送邮件。它专注于模板编辑、HTML 预览、草稿保存与导出 .eml / 复制 HTML，发送动作由你在本机邮件客户端完成。

我的邮件内容和授权码会泄露吗？

不会。你的配置和邮件内容保存在你当前浏览器的 localStorage 中，不会上传到服务器。授权码字段也只作本地记录，请妥善保管自己的设备。

导出的 .eml 文件能在哪些客户端打开？

标准 .eml 文件可被 Outlook、Foxmail、Apple 邮件、Thunderbird 等绝大多数邮件客户端识别。双击即可打开，补充收件人后直接发送。

变量占位符 {{姓名}} 没有被替换怎么办？

预览与导出时，只有「变量填充」区中已填写值的占位符才会被替换；未填写的占位符会原样保留（如 {{姓名}}），方便你发现遗漏。请确认在变量填充区填入了对应内容。

支持哪些邮件模板？

内置 6 套：自定义文案、面试邀请、入职通知、会议通知、生日祝福、放假通知。每套都带有合理的排版与常用变量，也可在填入后自由修改正文。

换电脑或清除浏览器数据后草稿还在吗？

不在。草稿保存在当前浏览器的本地存储中，清除浏览器数据、使用无痕模式或更换设备都无法恢复。重要模板建议导出 .eml 或复制 HTML 另行备份。
