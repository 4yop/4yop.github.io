使用指南与导出教程

支持格式

  • VCF (vCard 2.1 / 3.0 / 4.0)
  • CSV 输出（UTF-8 / UTF-8 BOM）
  • 最大 10MB
  • 兼容 Excel / WPS / Google Sheets

iPhone 导出 VCF

  1. 打开「设置」→「通讯录」
  2. 点击「导出通讯录」
  3. 选择通过 AirDrop 或邮件发送
  4. 也可使用 iCloud 网页版导出

Android 导出 VCF

  1. 打开「通讯录」App
  2. 进入设置 → 导入/导出
  3. 选择「导出到存储」
  4. 生成 .vcf 文件后传输到电脑

注意事项

  • Windows Excel 建议选 UTF-8 BOM
  • 制表符分隔可直接粘贴到 Excel
  • 多个电话/邮箱会分别导出
  • 中文姓名完整保留，不会拆分
