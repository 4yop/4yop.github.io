PDF 压缩

压缩含图片 / 扫描件的 PDF，浏览器本地处理，文件不上传

PDF 压缩：给臃肿的文件瘦身

扫描件、图片型 PDF 往往体积惊人——一张手机拍的页面就能顶上几百 KB 甚至几 MB。 PDF 压缩工具针对这类「含位图」的文档，在浏览器本地把内嵌的图片重新压缩成更紧凑的 JPEG， 再重建出一份体积更小的 PDF。整个过程在你的浏览器内完成，文件不会上传到任何服务器。

它能做什么

  • 压缩含图片 / 扫描件 / 照片的 PDF：逐页把位图重压缩为 JPEG 后重建，体积显著下降。
  • 提供三档力度：轻度（保质量）、标准（推荐）、深度（最小体积），按需选择。
  • 对不含图片的纯文字或矢量 PDF（如用 Word 导出的文档），会提示「无可压缩的位图」，避免无效操作。
  • 所有处理在浏览器本地完成，文件不上传，适合含敏感内容的文档。

技术原理

工具在浏览器内完成三步处理，不依赖后端接口：

  1. 检测：先用 pdf-lib 低层 API 扫描页面资源，判断文档是否含内嵌位图。
  2. 重压缩：用 pdf.js 把每一页渲染到画布，再以所选质量把画布导出为 JPEG（这一步是体积下降的关键）。
  3. 重建：用 pdf-lib 把各页的 JPEG 重新铺回对应尺寸的页面，序列化为一份新的紧凑 PDF。

使用建议与边界

  • 压缩主要针对位图。纯文字 PDF（Word/PPT 导出的矢量文本）本身已经很小，压缩效果有限，甚至可能略微变大。
  • 「深度压缩」会显著降低图片清晰度，适合仅用于屏幕预览、不要求打印的场景；需要保留清晰度的请选「轻度」。
  • 压缩后页数与页面布局不变，但图片型内容会按所选质量重采样，建议下载后核对关键页面是否清晰。

常见问题

为什么提示「该 PDF 不含图片」？

压缩功能针对内嵌位图（扫描件、照片）。如果你的 PDF 是用 Word、PPT 导出的纯文字 / 矢量文档，里面没有可压缩的位图，工具会直接提示，不做无效处理。这类文档通常已经很紧凑。

我的 PDF 会上传到服务器吗？

不会。检测、重压缩与重建都在你的浏览器本地完成，文档内容不会离开本机，适合处理含隐私或敏感信息的文件。

压缩后会变模糊吗？

会。压缩的本质是用更低质量的 JPEG 替换原图，体积越小清晰度损失越多。「轻度」档保留较多细节，「深度」档最省空间但图片最糊。请按用途选择，并在下载后核对关键页面。
