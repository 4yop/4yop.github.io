PDF 转 Markdown

将 PDF 中的文字提取并转为 Markdown 格式，浏览器本地处理，文件不上传

PDF 转 Markdown：把 PDF 文字变成可编辑的 Markdown

很多 PDF 是「只读」的——你想引用其中的段落、在笔记里整理要点、或者把文档迁移到博客， 但复制出来的文字往往丢失格式、换行错乱。 PDF 转 Markdown 工具在浏览器本地提取文字并用启发式规则还原基本结构： 标题变 #/##、列表保持编号、段落自动分组。 整个过程不依赖后端，文件不会上传到任何服务器。

它能做什么

  • 文字提取：从文本型 PDF（Word/PPT 导出、电子书等）逐页提取全部可选中文字。
  • 结构还原：通过字号差异检测标题（# / ##）、通过前缀模式保留列表（1. 2. 或 - *）、按间距自动分段落。
  • 输出标准 Markdown 文本，可直接粘贴到 Obsidian、Typora、GitHub 等任意 Markdown 编辑器。
  • 所有处理在浏览器本地完成，文件不上传。

适用范围

  • 适合：用 Word、Pages、Google Docs 导出的 PDF；电子书（EPUB 转的 PDF）；含文字层的报告/论文。
  • 不适合：纯扫描件/图片型 PDF（没有可选文字层，需先用 OCR 工具识别）；加密且禁止复制的 PDF（会提取失败）。

技术原理

工具在浏览器内完成两步处理：

  1. 文字提取：用 pdf.js 的 getTextContent() API 逐页获取每个文字项的位置和字体信息。
  2. 启发式排版：按 Y 坐标间距把文字项分组为段落，对比字号大小判断标题级别，匹配前缀模式保留列表格式，最终拼接成 Markdown 文本。

由于 PDF 本身不存储「语义」（它只记录每个字符的坐标），工具只能通过位置和样式推测结构。 结果通常需要少量人工校对——尤其是复杂表格和多栏布局。

常见问题

扫描件能用吗？

不能直接用。扫描件的每一页都是一张图片，没有可选文字层。请先使用本站的「PDF OCR 文字识别」工具将其转为带文字层的 PDF，再使用本工具转换为 Markdown。

提取结果不准确怎么办？

PDF 的文字是按「每个字符的位置」存储的，不是按句子或段落存储的。工具通过字符间的 Y 坐标距离来猜测哪些文字属于同一段落，通过字号来猜测标题。对于多栏布局、复杂表格或特殊排版的 PDF，结果可能需要手动调整格式。

我的 PDF 会上传到服务器吗？

不会。文字提取和格式转换都在你的浏览器本地完成，文档内容不会离开本机。
