这个工具能做什么

这页适合快速生成一份可编辑的 robots.txt， 支持 WordPress、Typecho、Discuz 预设，也能手动填写 Disallow、Allow、Crawl-delay 和 sitemap。

建议这样使用

  1. 先选 CMS 预设，快速带出常见目录规则。
  2. 再补充你自己站点的后台、临时目录或公开目录路径。
  3. 确认 sitemap 地址使用的是正式域名。
  4. 生成后复制或下载，再去线上 /robots.txt 自查一遍。

常见问题

写了 robots.txt 就等于页面保密了吗？ 不是。它只是在告诉爬虫“不建议抓”，不等于权限控制。

CSS 和 JS 要不要屏蔽？ 不建议默认全屏蔽，尤其是依赖前端渲染的页面，误封会影响搜索引擎理解内容。

Crawl-delay 一定有效吗？ 不同爬虫支持程度不同，所以它更适合作为辅助规则，不要把它当成核心控制手段。
