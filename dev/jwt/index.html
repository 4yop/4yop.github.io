JWT 解析工具

解析 JWT Token，查看 Header、Payload、Signature

输入 JWT Token

这个工具能做什么

这页适合快速查看 JWT 的 header 和 payload，先确认 exp、iat、nbf 这些时间字段是否合理，再配合后端日志判断到底是 token 真过期了，还是刷新链路、缓存和时间偏差出了问题。

建议这样排查

  1. 先把完整 token 粘贴进来，确认能否正常拆成三段。
  2. 重点看 payload 里的 exp、iat 和 nbf。
  3. 如果接口提示过期，先对比当前时间，再判断是不是客户端时钟或 refresh 逻辑有问题。
  4. 需要和后端沟通时，优先复制解码结果，不要手抄字段。

常见问题

能校验签名吗？ 这页主要做解码和查看，不负责用服务端密钥验证签名。

能解码就代表 token 可用吗？ 不代表。能解码只说明格式像 JWT，是否有效还要看签名、密钥和服务端校验。

内容会上传吗？ 当前页面在浏览器本地解析，适合先做第一轮排查。
