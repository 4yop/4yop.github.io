SVG格式转换 - SVG转PNG/JPEG/PDF在线工具

SVG格式转换工具可以将 SVG 矢量图转换为 PNG、JPEG、PDF 等位图格式，支持自定义输出尺寸和背景色。SVG 是矢量格式，放大不失真，但部分场景需要位图格式（如社交媒体上传、邮件嵌入），本工具可以快速完成格式转换。

下面介绍 SVG 格式的特点、转换原理和使用方法。

SVG 与位图的区别

SVG（Scalable Vector Graphics）是矢量图形格式，用 XML 描述图形的路径、形状和颜色，无论放大多少倍都不会失真。位图（PNG、JPEG 等）由像素点组成，放大后会出现锯齿和模糊。

SVG 适合图标、Logo、插画等线条图形，文件体积小且可编辑。位图适合照片、截图等复杂图像，色彩丰富但放大失真。将 SVG 转为位图时，需要指定输出尺寸和分辨率，尺寸越大文件越大。

SVG 转位图的技术原理

SVG 转位图的核心技术是 Canvas API。首先将 SVG 代码创建为 Image 对象，然后绘制到指定尺寸的 Canvas 上，最后通过 Canvas 的 toDataURL() 或 toBlob() 方法导出为 PNG/JPEG 格式。

转换质量取决于输出尺寸和 SVG 的复杂度。SVG 中的滤镜、渐变和动画在转换后会被"烘焙"为位图像素，无法再编辑。PDF 格式转换使用 Canvas 的 toBlob 方法配合 jsPDF 库实现，保留矢量特性。

常见问题

转换后图片模糊怎么办？

增大输出尺寸可以提升清晰度。建议输出尺寸至少为显示尺寸的 2 倍（适配 Retina 屏幕）。PNG 格式不会压缩画质，优先选择 PNG。

SVG 中的字体显示不正确？

SVG 中引用的字体需要在系统中安装才能正确渲染。建议在 SVG 中将文字转为路径（outline），避免字体依赖问题。

PNG 和 JPEG 选哪个？

需要透明背景选 PNG，不需要透明选 JPEG（文件更小）。SVG 图标和 Logo 建议用 PNG，照片类图片建议用 JPEG。

文件会上传到服务器吗？

不会，所有转换在浏览器本地完成，SVG 文件不会上传到任何服务器。转换完成后即可下载，数据不会留存。

支持多大的 SVG 文件？

取决于浏览器内存，一般支持几 MB 以内的 SVG 文件。过大的 SVG 可能导致转换失败，建议先压缩 SVG 再转换。

SVG 中的动画会保留吗？

不会，转换为位图后动画效果会丢失，只保留当前帧的静态画面。如需保留动画，请保持 SVG 格式或转为 GIF。
