它能帮你做什么？

1. 渐变调色盘——创造柔和的色彩背景

像什么：就像日落时天空从橙红到深紫的自然过渡，或者一杯饮料里不同颜色果汁的慢慢融合。

你能做：选择两种或更多颜色，决定它们混合的方向（直线还是圆形）和角度。立马就能得到一个独一无二的、有高级感的背景图。

适合：社交媒体封面图背景、海报大标题底色、演示文稿的幻灯片背景。

2. 阴影与灯光师——让元素“立”起来

像什么：就像给一张纸后面打一盏灯，让它产生漂浮的错觉；或者让文字看起来像是刻在背景上一样有深度。

你能做：调节“影子”的远近、模糊程度、颜色深浅。可以让一个方框、一张图片甚至一段文字立刻脱离背景，变得立体生动。

适合：商品展示图、按钮设计、需要重点突出的标题文字。

3. 个性相框——为内容添加精致外框

像什么：就像给珍贵的照片挑选不同材质和颜色的相框，或是笔记本上漂亮的装饰线。

你能做：选择边框的粗细、线条样式（实线、虚线、点线）、颜色，还能把四个角调成圆润的弧度。

适合：给重点内容或引言加框、制作头像边框、创建信息卡片。

4. 微动效魔术师——增加一点灵动感

像什么：就像让一张静态图片轻轻呼吸（淡入淡出），或者像指针一样匀速旋转，又或者像弹力球那样跳一下。

你能做：选择动画类型（淡入淡出、旋转、缩放等），调节速度快慢和运动节奏，控制它播放的次数。

适合：网站或公众号引导关注的图标、吸引注意力的提示元素、个人主页的标志。
