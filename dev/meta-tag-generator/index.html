使用说明

  • 将生成的代码复制到 HTML 文件的 <head> 标签内即可
  • charset 决定浏览器如何解析网页编码，推荐 UTF-8
  • viewport 控制移动端显示效果，自适应模式可让页面在手机上正常浏览
  • keywords 虽然现代搜索引擎权重降低，但仍有辅助作用
  • description 会显示在搜索引擎结果中，影响点击率
  • robots 告诉搜索引擎爬虫是否允许抓取和收录
