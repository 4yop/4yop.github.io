下面介绍快捷键的重要性、使用方法以及高效记忆技巧。

为什么要记住快捷键

快捷键（Keyboard Shortcuts）是通过键盘组合键快速执行操作的方式。每次将手从键盘移到鼠标再移回来，大约需要 2-3 秒，一天累计可能浪费 30 分钟以上。而使用快捷键只需 0.5 秒，长期积累的效率提升非常可观。

快捷键的另一个优势是减少重复性劳损（RSI）的风险。频繁使用鼠标容易导致手腕疲劳，而键盘操作对手腕的压力更小。养成使用快捷键的习惯，既提升效率又保护健康。

Windows 与 Mac 快捷键对照

Windows 和 Mac 的快捷键存在系统性对应关系：Ctrl 键在 Mac 上对应 Command 键，Alt 键对应 Option 键。例如，Windows 的 Ctrl+C 复制，在 Mac 上是 Command+C；Ctrl+Shift+N 新建文件夹，Mac 上是 Command+Shift+N。

部分快捷键在两个平台上的组合完全不同，如任务管理器在 Windows 上是 Ctrl+Shift+Esc，Mac 上是 Command+Option+Esc。本工具会同时显示两个平台的快捷键，方便跨平台用户查阅。

常见问题

快捷键可以自定义吗？

大部分软件支持自定义快捷键，具体方法请查看对应软件的设置。VS Code、Photoshop 等软件提供了完善的快捷键自定义功能。

Mac 和 Windows 快捷键有什么区别？

Mac 通常用 Command 键替代 Windows 的 Ctrl 键，部分快捷键组合不同。本工具支持一键切换平台查看对应的快捷键。

收录了多少快捷键？

覆盖主流软件的数百个常用快捷键，持续更新中。如需补充特定软件的快捷键，欢迎反馈。

如何快速记忆快捷键？

建议每次只学 3-5 个，在日常工作中刻意使用直到形成肌肉记忆。也可以打印常用快捷键贴在显示器旁边。

快捷键在所有语言版本中都一样吗？

大部分快捷键在不同语言版本中是相同的，但少数快捷键可能因键盘布局不同而有差异。例如法语 AZERTY 键盘的快捷键位置与 QWERTY 不同。

Linux 快捷键有收录吗？

目前主要收录 Windows 和 Mac 平台的快捷键。Linux 桌面环境的快捷键与 Windows 类似，可参考 Windows 快捷键使用。
