MAC地址查询工具

查询MAC地址对应的设备制造商信息，支持多种格式输入

MAC地址查询

支持格式：00:0C:39:AB:CD:EF、00-0C-39-AB-CD-EF、000C.39AB.CDEF、000C39ABCDEF

可输入完整12位MAC地址或仅前6位OUI段（厂商标识）进行查询

使用说明

什么是MAC地址？

MAC地址（Media Access Control Address）是网络设备的全球唯一硬件标识符。由48位二进制组成，通常表示为12位十六进制字符。

MAC地址结构

  • OUI（前24位）：组织唯一标识符，由IEEE分配给设备制造商
  • NIC（后24位）：网络接口控制器标识，由厂商自行分配

如何查看本机MAC地址

  • Windows：设置 → 网络和Internet → 高级网络设置 → 硬件属性中的物理地址
  • macOS：系统设置 → 网络 → 当前连接 → 详细信息 → 硬件标签页
  • Linux：终端运行 ifconfig 或 ip link show 命令查看 ether 字段
