使用说明

什么是MAC地址？

MAC地址（Media Access Control Address）是网络设备的全球唯一硬件标识符。由48位二进制组成，通常表示为12位十六进制字符。

MAC地址结构

  • OUI（前24位）：组织唯一标识符，由IEEE分配给设备制造商
  • NIC（后24位）：网络接口控制器标识，由厂商自行分配

如何查看本机MAC地址

  • Windows：设置 → 网络和Internet → 高级网络设置 → 硬件属性中的物理地址
  • macOS：系统设置 → 网络 → 当前连接 → 详细信息 → 硬件标签页
  • Linux：终端运行 ifconfig 或 ip link show 命令查看 ether 字段

MAC地址查询 - 设备制造商识别工具

MAC地址查询工具可以根据MAC地址识别设备制造商。MAC地址的前24位称为OUI（Organizationally Unique Identifier），由IEEE分配给设备制造商，因此通过OUI可以查询到设备的制造商信息。本工具基于IEEE官方OUI数据库，支持多种格式输入和批量查询。

下面详细介绍MAC地址的结构、查询方法以及常见应用场景。

什么是 MAC 地址

MAC地址（Media Access Control Address）是网络设备的物理地址，由48位二进制数组成，通常表示为6组十六进制数（如 AA:BB:CC:DD:EE:FF）。MAC地址在全球范围内唯一，烧录在网卡的固件中，用于局域网内的设备识别和数据帧传输。

MAC地址的前24位（前三组）是OUI，由IEEE注册管理机构分配给各设备制造商。例如，Apple的OUI前缀包括 00:03:93、AC:DE:48 等，Samsung的OUI前缀包括 00:12:FB、D0:C7:C0 等。通过查询OUI，可以确定设备的生产厂商。

OUI 数据库原理

IEEE注册管理机构负责维护全球OUI数据库，每个申请OUI的厂商需要缴纳注册费用。OUI数据库包含三种类别：MA-L（MAC Address Block Large，24位）、MA-M（MAC Address Block Medium，28位）和 MA-S（MAC Address Block Small，36位），分别对应不同规模的地址块。

本工具使用的是IEEE官方发布的MA-L数据库，覆盖了绝大多数已注册的设备制造商。查询时只需提取MAC地址的前24位，在数据库中匹配对应的组织名称即可。数据库会随IEEE的更新而定期同步。

常见问题

能查到具体设备吗？

不能，MAC地址只能查到设备制造商（如 Apple、Samsung），无法定位到具体设备型号或位置。后24位由厂商自行分配，不公开对应关系。

查询结果准确吗？

基于IEEE官方OUI数据库，结果准确可靠。但部分厂商可能使用子厂商的OUI，导致显示的厂商名称与品牌名不完全一致。

支持查询所有厂商吗？

覆盖绝大多数已注册的厂商，极少数未注册的OUI可能查不到。虚拟MAC地址（随机化MAC）可能无法查询到有效厂商。

什么是MAC地址随机化？

为保护隐私，现代手机在扫描WiFi时会使用随机生成的MAC地址，而非真实MAC地址。这种随机MAC的OUI通常无法查询到有效厂商信息。

如何查看自己设备的MAC地址？

Windows系统在命令行输入 ipconfig /all，Mac系统在终端输入 ifconfig，手机在设置-关于本机中可以查看WiFi MAC地址。

MAC地址可以修改吗？

硬件MAC地址烧录在网卡固件中无法修改，但操作系统层面可以临时更改MAC地址（称为MAC地址伪装），这在某些网络调试场景中有用。
