图片模糊背景填充：给照片套一个虚化底，轻松适配各种比例

图片模糊背景填充把一张普通照片变成「清晰主体 + 虚化背景」的构图：工具会用同一张图放大并做高斯模糊后铺满整个画布，再把原图作为清晰前景居中放置。这样既保留了完整的主体，又补足了目标比例所需的留白，非常适合横图转竖图、竖图转横图，以及短视频封面、社媒配图的尺寸统一。

主要功能

  • 两种输出模式：按比例（1:1、4:3、3:4、16:9、9:16、3:2、2:3）或自定义固定宽高（100–4000 像素）。
  • 模糊强度调节：0–100 滑动控制背景虚化程度。
  • 主体与背景缩放：可分别调整前景主体大小（50%–100%）和背景放大倍数（100%–200%）。
  • 多格式导出：支持原格式、PNG、JPG、WEBP 下载。
  • 多种上传方式：点击选择、拖拽文件，或直接 Ctrl+V 粘贴剪贴板图片。
  • 本地处理：所有模糊与合成都在浏览器本地完成，图片不上传服务器。

使用小技巧

想让背景更干净，可把「背景放大」调大一些，减少原图边缘露出；想突出主体，适当降低「主体缩放」会让四周留白更多。背景处理基于 HTML5 Canvas API 的高斯模糊滤镜，在浏览器本地实时计算。
