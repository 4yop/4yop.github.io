图片拼接工具 - 多张图片合并为一张长图

图片拼接是将多张图片按指定方向（水平或垂直）合并成一张大图的操作。可以设置间距、背景颜色、对齐方式等参数，支持预览和下载拼接结果。

下面介绍图片拼接工具的功能和使用方法。

什么是图片拼接工具

图片拼接是将多张图片组合成一张完整图像的操作。常用于将多张截图拼成长图、将多张证件照拼成一排、制作对比图等场景。支持水平和垂直两种拼接方向，可自定义间距、对齐方式和背景色。

核心功能

水平拼接

从左到右排列图片

垂直拼接

从上到下排列图片

间距设置

设置图片之间的间距

背景颜色

自定义背景填充色

对齐方式

左/中/右 或 上/中/下对齐

本地处理

所有操作在浏览器本地完成

使用教程

  1. 上传需要拼接的多张图片。
  2. 选择拼接方向（水平或垂直）。
  3. 调整间距、对齐方式、背景颜色等参数。
  4. 点击开始拼接，预览并下载结果。

应用场景

  • 截图拼接：将多个聊天记录截图拼成长图
  • 证件照排版：将多张一寸照拼成一排打印
  • 对比图制作：将修改前后的图片并排展示
  • 素材整合：将分散的图片元素整合在一起

技术原理

图片拼接工具基于 Canvas API 实现。根据用户选择的拼接方向和参数，计算每张图片的位置坐标，创建足够大的 Canvas 容器，依次绘制每张图片到对应位置，最后导出为 PNG 图片。支持通过 CanvasRenderingContext2D 设置背景色、处理透明区域等。

常见问题

最多能拼接多少张图片？

没有严格限制，但过多图片可能导致内存问题。

拼接后图片质量会下降吗？

不会，PNG 格式无损保存原始质量。

可以调整图片顺序吗？

可以通过拖拽调整上传图片的顺序。

不同尺寸的图片如何对齐？

提供左、中、右（或上、中、下）三种对齐方式。

图片会上传到服务器吗？

不会，所有拼接操作在浏览器本地完成。

输出什么格式？

默认输出 PNG 格式，保持最佳质量。
