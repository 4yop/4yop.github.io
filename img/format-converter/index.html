图片格式转换是将图片从一种格式转换为另一种格式的操作。不同格式有不同特点：JPG 适合照片、PNG 支持透明、WebP 体积小质量好。在线转换器支持批量将图片在 JPG、PNG、WebP 等格式间互转，无需安装软件。

下面介绍图片格式转换器的功能和使用方法。

什么是图片格式转换器

图片格式决定了图片的编码方式和特性。JPG 适合照片但有损压缩，PNG 支持透明但文件较大，WebP 是现代格式兼顾体积和质量。不同场景需要不同格式，在线格式转换器让你无需安装软件即可快速转换图片格式。

技术原理

图片格式转换基于 Canvas API 实现。将原图绘制到 Canvas 上，然后通过 Canvas.toDataURL() 或 Canvas.toBlob() 方法以目标格式的 MIME 类型导出。JPG 质量通过 quality 参数控制，WebP 同理。透明通道在 PNG 和 WebP 间保留，JPG 不支持透明。

常见问题

转换后质量会下降吗？

PNG 无损转换不会，JPG 和 WebP 可设置质量参数控制。

JPG 转 PNG 文件会变大吗？

会，PNG 是无损格式，JPG 的压缩伪影也会被保留导致文件更大。

支持批量转换吗？

支持，可以同时上传多张图片统一转换。

WebP 格式兼容性如何？

现代浏览器都支持 WebP，旧版 IE 不支持。

图片会上传到服务器吗？

不会，所有格式转换在浏览器本地完成。

可以设置输出质量吗？

可以，JPG 和 WebP 格式支持 0-100% 质量设置。
