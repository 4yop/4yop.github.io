技术原理

本工具基于 Fetch API 从多个公开 JSON 图库接口随机获取图片 URL，通过 <img> 标签加载并展示。收藏功能使用浏览器 IndexedDB 数据库实现客户端持久化存储，以图片 URL 作为主键确保唯一性。下载功能利用 Blob API 处理跨域图片资源，打包下载则通过 JSZip 库将多张图片压缩为 ZIP 格式。瀑布流布局采用 CSS column-count 多列布局实现，支持滚动自动加载更多（分页机制）。

常见问题

图片加载不出来怎么办？

部分图片来源可能存在跨域限制或链接失效，点击刷新按钮重新获取即可跳过无法加载的图片。

收藏的图片会丢失吗？

不会。收藏使用浏览器 IndexedDB 本地存储，只要不手动清除浏览器数据，收藏记录会一直保留。但注意清除浏览器数据会导致收藏丢失。

可以下载所有收藏的图片吗？

可以。点击打包下载按钮，系统会将所有收藏的图片打包为一个 ZIP 文件供你下载。

手机上可以使用吗？

可以，工具完全适配移动端浏览器，响应式布局支持手机和平板设备访问使用。

图片数据来源是什么？

图片来自多个公开的 JSON 图库接口，工具仅做聚合展示，不存储任何图片数据到服务器。

如何删除收藏的图片？

打开收藏列表，鼠标悬停在图片上会出现删除按钮，点击后确认即可删除该收藏。
