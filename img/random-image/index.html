为什么需要「随机」生成的图片？

在设计和开发过程中，「我需要一张图片但还没确定用什么」是一个高频场景。占位图是其中最常见的用途：前端开发者在页面布局阶段需要临时填充图片区域；设计师在做原型时需要快速验证视觉效果；内容创作者在发布前需要一张配图来预览排版。传统的做法是从网上找免费素材图或使用 Lorem Picsum 等服务——但这些方案都有局限性：素材图可能存在版权风险、外部服务可能不稳定或加载慢、且无法精确控制尺寸和风格。

程序化生成（Procedural Generation）提供了一种不同的思路：不使用任何预设图片资源，而是通过算法实时创建。这意味着你永远不会遇到「找不到合适的图」的问题——因为每一张都是独一无二的、按需生成的、完全可控的。

六种样式详解

纯色（Solid）
最基础的样式。生成单一颜色的实心矩形。听起来简单，但它是最常用的占位图类型——用于测试布局、对比度、文字可读性等基础属性时，纯色背景能排除一切视觉干扰。
渐变（Gradient）
线性或径向的颜色过渡。比纯色更有层次感，适合作为网页背景、PPT 封面底图、App 启动页背景等需要一定视觉丰富度但不抢夺主体内容的场景。
噪点（Noise）
每个像素点都被赋予随机的颜色值，形成类似电视雪花屏的效果。适合作为纹理叠加层、赛博朋克风格的背景元素、或者测试图像压缩算法的极限表现。
几何图形（Geometric）
由随机位置和大小的圆形、矩形、三角形等基本图形组成。具有现代感和设计感，适合科技类产品的宣传物料背景。
像素艺术（Pixel Art）
模拟低分辨率（如 16×16 或 32×32）的像素画风格，然后放大到目标尺寸。复古游戏爱好者会喜欢这种风格。
抽象艺术（Abstract Art）
结合多种算法（贝塞尔曲线、随机多边形、颜色混合等）生成的非具象图案。每次结果都不可预测，有时会产生令人惊喜的「意外美感」。

常见问题

生成的图片可以商用吗？有版权问题吗？

完全没有版权问题。因为这些图片是由你在点击「生成」按钮的那一刻通过算法即时创建的，不存在「原作者」——你就是作者。没有第三方版权、无需署名、可用于包括商业用途在内的任何场景（包括转售、修改、二次创作）。这是程序化生成相比传统素材库最大的优势之一：零版权顾虑。

如何生成特定颜色的图片？

本工具提供五种颜色模式来控制输出配色：（1）随机——完全不限制，每次生成完全不同的颜色；（2）暖色调——红、橙、黄及其邻近色系；（3）冷色调——蓝、绿、紫系；（4）灰度——从黑到白的灰色梯度；（5）自定义——如果你选择了自定义模式并指定了具体颜色值（如品牌主色），所有生成的图片都会围绕该色调展开。对于纯色样式，自定义模式可以直接生成精确的目标颜色图片。

支持的最大尺寸是多少？

工具允许设置最大 2000×2000 像素的输出尺寸。这个限制是基于以下考虑：（1）浏览器 Canvas 的性能上限——超大尺寸的复杂图形渲染可能导致卡顿；（2）实际需求——大多数占位图和背景图的合理尺寸都在 2000px 以内；（3）文件大小——过大的 PNG 文件下载和使用都不方便。如果你确实需要更大尺寸（如 4K 分辨率的 3840×2160），建议先生成 2000px 的版本再用图片缩放工具放大——纯色和渐变样式的放大几乎无质量损失。

同一次设置下再次点击生成，结果一样吗？

不一样。每次点击生成都会重新执行随机算法，产生全新的结果——即使所有参数（尺寸、样式、颜色模式）保持不变。这正是「随机」的含义。如果你对某次生成的结果特别满意，请立即保存，因为下次点击几乎不可能得到完全相同的一张（理论上存在重复概率，但对于像素级的组合空间来说概率趋近于零）。工具提供了历史记录功能，可以查看最近生成的几张图片并重新下载。

和 Placeholder.com / Unsplash 等服务相比有什么优势？

核心优势在于可控性和隐私性：Placeholder 等外部服务依赖网络请求，可能因服务器宕机、DNS 问题、CDN 缓存延迟导致加载失败；而且你的访问记录可能会被日志记录。本工具在本地运行，不依赖任何外部服务，离线也能使用。另外，外部服务的样式选项有限（通常只有纯色+文字），而本工具提供了几何图形、噪点、抽象艺术等更丰富的选择。劣势方面，外部服务可能有更多预设模板（如包含特定文字、人物照片等），这些是纯算法难以模拟的。

生成的图片可以用作网站背景吗？

完全可以，但有几点建议：（1）文件大小——复杂的几何图形和抽象艺术 PNG 可能较大（100KB-500KB），如果用作全站背景建议先用压缩工具处理；（2）重复性——如果背景图小于视口面积，浏览器会自动平铺重复（CSS `background-repeat` 默认值）。如果需要无缝衔接，纯色和渐变样式天然满足；其他样式可能需要在 CSS 中设置 `background-repeat: no-repeat` 并配合合适的定位策略；（3）可读性——确保背景不会干扰前景文字的阅读。噪点和复杂几何图形尤其需要注意——可能需要叠加一层半透明的白色遮罩来提升文字可读性。
