图片缩放工具 - 在线调整图片尺寸批量缩放

图片缩放是调整图片尺寸的常用操作，包括放大和缩小。在线缩放工具支持按百分比、按像素值或按预设尺寸调整图片大小，可以锁定宽高比保持比例，也支持批量处理多张图片。

下面介绍图片缩放工具的功能和使用方法。

什么是图片缩放工具

图片缩放是调整图片尺寸的基本操作，在网页开发、打印制作和社交分享中经常需要。缩放分为放大和缩小，缩小通常不会损失质量，但放大可能导致模糊。在线缩放工具支持按百分比或精确像素值调整，批量处理更高效。

核心功能

百分比缩放

按百分比调整图片大小

像素精确

输入精确的宽高像素值

锁定比例

保持宽高比不变形

预设尺寸

常用尺寸一键选择

批量处理

同时调整多张图片尺寸

本地处理

所有操作在浏览器本地完成

使用教程

  1. 上传需要缩放的图片，支持批量上传。
  2. 选择缩放方式，输入目标尺寸或百分比。
  3. 勾选锁定宽高比保持比例。
  4. 预览效果后下载缩放后的图片。

应用场景

  • 网页适配：调整图片尺寸适配网页显示
  • 打印准备：调整图片到打印所需分辨率
  • 社交平台：调整为社交平台要求的尺寸
  • 批量处理：统一调整多张图片尺寸

技术原理

图片缩放工具基于 Canvas API 实现。创建目标尺寸的 Canvas，通过 drawImage 方法将原图绘制到新尺寸的画布上。缩放算法使用浏览器内置的双三次插值，缩小图片效果良好，放大图片可能模糊。批量处理通过队列逐个处理。

常见问题

放大图片会模糊吗？

适度放大（2倍以内）效果可接受，大幅放大建议使用 AI 放大工具。

缩小图片会损失质量吗？

缩小是无损的，但像素信息会减少，无法再恢复到原始尺寸。

支持批量处理吗？

支持，可以同时上传多张图片并统一调整尺寸。

可以只调整宽度或高度吗？

可以，取消锁定宽高比后可以独立设置宽高。

图片会上传到服务器吗？

不会，所有缩放操作在浏览器本地完成。

支持哪些图片格式？

支持 JPG、PNG、WebP 等常见格式输入和输出。
