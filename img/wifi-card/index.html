WiFi 名片生成器 - WiFi 密码卡片设计二维码制作

WiFi 名片是将 WiFi 网络名称和密码以美观的卡片形式展示，并附带二维码方便扫码连接。在家中接待客人、咖啡馆、酒店等场所，WiFi 名片可以让访客快速获取网络信息，无需口口相传密码。支持自定义卡片样式、颜色和布局，一键生成可打印的 WiFi 名片。

下面介绍 WiFi 名片生成器的功能和使用方法。

什么是 WiFi 名片

WiFi 名片是一种将 WiFi 连接信息（网络名称、密码、加密方式）以卡片形式展示的设计。卡片上通常包含一个WiFi 二维码，手机扫码即可自动连接网络，无需手动输入密码。WiFi 二维码遵循标准格式（WIFI:T:WPA;S:网络名;P:密码;;），大多数手机相机和扫码工具都能识别。

核心功能

WiFi 二维码

扫码自动连接，无需手动输入密码

自定义样式

选择卡片颜色、字体和布局风格

加密方式

支持 WPA/WPA2、WEP 和无密码

隐藏密码

可选择在卡片上隐藏密码显示

高清导出

生成适合打印的高清名片图片

本地生成

所有操作在浏览器本地完成

使用教程

  1. 输入 WiFi 网络名称（SSID）和密码，选择加密方式。
  2. 选择卡片样式和颜色，可以隐藏密码显示。
  3. 预览名片效果，确认二维码可以正常扫码。
  4. 下载名片图片，打印后放在家中或店铺供客人使用。

应用场景

  • 家庭接待：放在客厅让客人扫码连接 WiFi
  • 咖啡馆酒店：在桌面放置 WiFi 名片方便顾客
  • 办公场所：在会议室放置访客 WiFi 连接信息
  • 活动展会：为参会人员提供便捷的网络连接

技术原理

WiFi 名片生成器基于 Canvas API 和二维码生成库实现。WiFi 二维码遵循标准格式 WIFI:T:WPA;S:网络名;P:密码;;，手机扫码后自动解析并连接网络。名片卡片通过 Canvas 绘制，包括背景、文字、图标和二维码，最终导出为高清 PNG 图片。整个生成过程在浏览器本地完成。

常见问题

手机扫码能直接连接吗？

大多数现代手机（iOS 11+、Android 8+）支持扫描 WiFi 二维码自动连接，无需手动输入密码。

支持 5G WiFi 吗？

支持，WiFi 二维码只包含网络名称和密码，不区分频段，5G 和 2.4G 网络都适用。

密码安全吗？

WiFi 密码以明文存储在二维码中，请只在可信场所使用。可以选择隐藏卡片上的密码显示。

可以打印出来使用吗？

可以，导出的图片分辨率足够打印，建议使用彩色打印机效果更好。

密码会上传到服务器吗？

不会，所有名片生成和二维码编码在浏览器本地完成，WiFi 信息不会上传到服务器。

支持中文 WiFi 名称吗？

支持，WiFi 二维码标准支持 UTF-8 编码，中文网络名称可以正常识别。
