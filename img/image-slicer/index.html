图片裁剪工具 - 在线裁剪图片尺寸比例

图片裁剪是从图片中截取指定区域的操作。可以自由拖动裁剪框选择区域，也支持预设常用比例（如 1:1 正方形、16:9 宽屏、4:3 标准等），裁剪后可预览和下载。

下面介绍图片裁剪工具的功能和使用方法。

什么是图片裁剪工具

图片裁剪是从原始图片中选择性地保留一部分区域的操作。与缩放不同，裁剪不会改变保留区域的分辨率和清晰度。常用于去除图片多余部分、调整构图、适配特定显示区域等场景。

核心功能

自由裁剪

自由拖动选择任意区域

固定比例

预设 1:1 / 4:3 / 16:9 等

实时预览

即时查看裁剪效果

旋转翻转

旋转90度或镜像翻转

高精度输出

保持原图分辨率不变

本地处理

所有操作在浏览器本地完成

使用教程

  1. 上传需要裁剪的图片。
  2. 拖动裁剪框选择要保留的区域，或选择固定比例。
  3. 可调整位置、旋转角度等。
  4. 点击确认裁剪，下载结果图片。

应用场景

  • 头像制作：裁剪为正方形头像
  • 封面图制作：裁剪为 16:9 比例封面
  • 证件照裁剪：按标准尺寸裁剪
  • 去水印/去边框：裁掉不需要的区域

技术原理

图片裁剪基于 Canvas API 实现。用户通过交互确定裁剪区域（x, y, width, height），然后创建对应尺寸的目标 Canvas，使用 drawImage() 方法的九参数版本将原图的指定区域绘制到新 Canvas 上，最后导出为图片文件。

常见问题

裁剪后图片会变模糊吗？

不会，裁剪只是选取部分区域，不涉及缩放，分辨率不变。

有哪些预设比例？

常用比例包括 1:1（正方形）、4:3、3:4、16:9、9:16 等。

可以旋转图片吗？

支持 90 度旋转和水平/垂直翻转。

支持撤销重做吗？

支持，可以在裁剪过程中随时撤销操作。

图片会上传到服务器吗？

不会，所有裁剪操作在浏览器本地完成。

输出格式是什么？

默认保持原图格式，也可选择转换为其他格式。
