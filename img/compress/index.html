图片压缩工具 - 在线批量压缩图片减小体积

图片压缩是在尽量保持图片质量的前提下减小文件体积的操作。压缩分为有损压缩和无损压缩，有损压缩通过降低质量减小体积，无损压缩通过优化编码减小体积。在线压缩工具支持批量处理，自定义压缩质量。

下面介绍图片压缩工具的功能和使用方法。

什么是图片压缩工具

图片压缩是优化网页性能的重要手段，过大的图片会严重影响网页加载速度。有损压缩通过降低图片质量减小体积，适合照片类图片；无损压缩通过优化编码减小体积，适合图标和截图。合理压缩可以在保持视觉质量的同时大幅减小文件体积。

使用教程

  1. 上传需要压缩的图片，支持批量上传。
  2. 设置压缩质量或目标体积。
  3. 点击压缩，查看压缩前后体积对比。
  4. 满意后下载压缩后的图片。

应用场景

  • 网页优化：压缩图片加快网页加载速度
  • 邮件发送：压缩图片减小附件体积
  • 存储节省：压缩图片节省存储空间
  • 上传限制：压缩图片满足平台上传限制

技术原理

图片压缩基于 Canvas API 的质量参数实现。将原图绘制到 Canvas 上，通过 Canvas.toBlob() 方法的 quality 参数控制输出质量（0-1），值越低体积越小但质量越差。WebP 格式在相同质量下体积比 JPG 更小。目标体积模式通过二分法自动寻找最佳质量值。

常见问题

压缩后图片会模糊吗？

适度压缩（质量 70-85%）几乎看不出差别，过度压缩会明显模糊。

可以指定目标体积吗？

可以，设置目标体积后工具自动调整质量参数。

批量压缩支持多少张？

取决于浏览器性能，一般建议不超过 30 张。

PNG 可以压缩吗？

可以，PNG 转 JPG 或 WebP 可以大幅减小体积。

图片会上传到服务器吗？

不会，所有压缩操作在浏览器本地完成。

压缩比例一般多大？

JPG 质量 80% 通常可压缩 50-70%，WebP 压缩率更高。
