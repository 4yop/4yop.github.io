两种常见的命名方式

连写方式（驼峰式）

就像骆驼的背一样有起伏，把多个单词连在一起写，每个单词的首字母大写。

例如：

  • • 用户名字 → userName
  • • 我的文档 → myDocument
  • • 首页标题 → homePageTitle

分隔方式（下划线式）

用下划线把单词分开，就像给每个单词划出独立的小隔间。

例如：

  • • 用户名字 → user_name
  • • 我的文档 → my_document
  • • 首页标题 → home_page_title

这两种方式各有特点，但在不同场合可能需要统一成其中一种。比如有些系统只认其中一种格式，这时候就需要进行转换。

你可能想知道

转换后会改变原意吗？

不会。这只是改变单词的连接方式，就像把“北京上海”写成“北京_上海”一样，内容本身不变。

支持中文转换吗？

这个工具主要针对英文单词的转换。中文内容本身没有这种连接方式的问题。
