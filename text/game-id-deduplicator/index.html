使用说明

使用场景

  • 游戏账号注册时ID重复
  • 多个小号使用相似ID
  • 论坛、社区昵称去重
  • 批量注册账号需求

特殊符号说明

  • 零宽字符: 完全不可见，推荐使用
  • 不可见空格: 特殊空格字符
  • Unicode控制符: 控制字符
