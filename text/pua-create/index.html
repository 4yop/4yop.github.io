五种PUA话术模式解析

打压贬低

通过不断贬低对方的价值，让对方产生自我怀疑。"你也就这样了"、"除了我没人会要你"。目的是摧毁自信，让对方觉得自己离不开操控者。

忽冷忽热

时而热情似火，时而冷若冰霜，让对方情绪起伏不定。今天甜言蜜语，明天突然消失。这种不确定性会让对方更加依赖和焦虑。

制造愧疚

把所有问题归咎于对方，让对方感到愧疚。"我这样做都是因为你"、"如果不是你，我也不会这样"。通过愧疚感来控制对方的行为。

孤立控制

试图切断对方与朋友、家人的联系。"他们都不理解你，只有我懂你"、"你不需要那些朋友"。目的是让对方只能依赖操控者。

虚假承诺

许下美好的承诺却从不兑现。"等我们在一起了，一切都会好的"、"我以后一定改"。用未来的美好来换取当下的服从。
