亮点标签系统

除了整体风格外，你还可以通过勾选"评价亮点"来定向强化某些维度的描述。通用商品模式下可选：质量好、物流快、服务棒、性价比高、包装精美；外卖模式下可选：味道好、分量足、配送快、包装严实、超划算。每选中一个标签，生成的评论文本中就会增加一段针对该亮点的详细描写段落。不选标签的话系统会随机挑选一个亮点来填充，确保生成的评价内容充实而非空洞。你也可以同时选多个标签来组合出更丰富的评价——比如同时勾选"质量好"+"物流快"+"性价比"，就会得到一段涵盖三个维度的好评。

生成机制揭秘

每条好评都由四个部分拼接而成：开头句 + 名称植入 + 亮点展开 + 结尾升华。开头句从对应风格的 opening 语料库中随机抽取，负责定调情绪；名称植入会将你输入的商品名或菜品名以自然的方式嵌入到句子中；亮点展开则根据你选择的标签（或随机标签）从 features 语料库中抽取对应的详细描述句子；结尾从 closing 语料库中抽取总结性语句收束全文。由于每个部分的语料库都包含数十条备选句子且采用不放回随机抽样，即使参数完全相同，多次生成也会产出不同的结果。你可以一次性批量生成 1-10 条，从中挑选最满意的那条使用。

常见问题

生成的好评可以直接复制使用吗？需要注意什么？

可以一键复制单条或全部评价到剪贴板，然后粘贴到平台的评价框中发布。但强烈建议你在复制后进行至少 30 秒的快速审阅和微调——检查是否有与实际情况不符的细节描述（比如好评说"物流很快"但你实际等了一周），适当替换一两个词汇让评价更贴合你的真实体验。平台的风控系统会检测机械式重复评价和跨账号同文案行为，所以即使使用工具生成，也请务必做个性化修改后再提交。

语料库的内容是哪里来的？会不断更新吗？

当前语料库由团队人工编写和维护，参考了各大电商平台热门评价的真实语言风格和常用表达模式进行创作，确保生成内容的自然度和真实感。每个分类下包含数十条不重复的高质量模板句子，覆盖了大多数常见的好评表达需求。我们会定期根据用户反馈和平台规则变化对语料库进行迭代更新——新增流行表达方式、淘汰过时用语、优化各风格之间的差异化。如果你觉得某个特定品类（如母婴用品、图书）的评价语料不够丰富，也可以通过反馈渠道建议我们扩展。

用这个工具生成评价违反平台规则吗？

⚠️ 这是一个需要严肃对待的问题。本工具的设计初衷是帮助真实消费者更好地表达自己的购物体验，解决"有好评意愿但文笔有限"的痛点。如果你确实购买了商品并真心满意，用它辅助撰写评价内容是完全合理的——就像用翻译软件辅助写英文邮件一样。但是，如果用于以下用途则可能违规甚至违法：（1）未实际购买商品而虚假好评（刷单）；（2）商家组织大量账号批量生成虚假评价；（3）在有偿评价交易中使用工具生成内容。各电商平台的服务条款均明确禁止虚假评价行为，情节严重者可能导致账号封禁乃至法律风险。页面顶部的免责声明请务必认真阅读。

可以自定义添加自己的常用评价模板吗？

当前版本暂不支持用户自定义语料库功能。所有模板句子均为预置内容，无法在界面上增删改。不过你可以采用一个变通方法：先利用工具生成基础框架，然后在输入框或复制后的文本中进行个性化修改和补充。我们计划在未来版本中加入"我的模板"功能，允许用户保存自己撰写的优秀评价模板并在生成时优先使用。如果你有这个需求，欢迎通过反馈渠道告诉我们，这会影响我们的开发优先级排序。

支持哪些电商平台和外卖平台？

通用商品模式适用于几乎所有主流电商平台，包括淘宝、天猫、京东、拼多多、抖音电商、快手小店、苏宁易购、唯品会等——本质上只要是需要写文字评价的商品购物场景都可以使用。外卖美食模式则针对美团外卖、饿了么两大主流平台设计，同时也适用于肯德基、麦当劳等品牌官方小程序的点餐评价场景。虽然不同平台的评价界面略有差异（字数限制、是否支持图片等），但生成的文本内容本身是通用的，不受平台限制。

生成的内容字数大概是多少？平台有字数限制怎么办？

单条评价的字数通常在 80-200 个汉字之间（取决于选择了多少个亮点标签），这个长度恰好落在大多数平台推荐的评价字数区间内——太短显得敷衍（平台可能会判定为低质量评价），太长没人看。淘宝的评价框建议 50 字以上，京东 20 字以上即可，拼多多 10 字以上。如果你的目标平台有特殊字数要求（比如某些品牌需要 500 字以上的深度测评），你可以将工具生成的评价作为核心框架，在此基础上自行扩充细节描述来达到字数要求。批量生成多条时，总字数 = 单条平均字数 × 生成数量，请注意不要超出剪贴板的合理容量。

手机上使用体验如何？

移动端适配完善。在小屏手机上，表单区和结果区会自动切换为上下堆叠布局，标签选择按钮和生成按钮的触控面积都做了加大处理，方便手指操作。复制按钮在每条评价右侧独立显示，点击后调用系统剪贴板 API 完成复制并弹出 Toast 提示。唯一需要注意的是：在微信内置浏览器中使用时，由于微信的安全策略限制，navigator.clipboard API 可能不可用，此时复制功能会降级为 fallback 方案（创建临时 textarea → execCommand('copy')），功能正常但体验略逊于标准浏览器。推荐在 Safari（iOS）或 Chrome（Android）中使用以获得最佳体验。
