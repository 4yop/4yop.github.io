四种转换格式详解

全大写 (UPPERCASE)

示例：Hello World -> HELLO WORLD。将所有英文字母转换为大写。适用于强调、标题、缩写词或需要突出显示的场景。编程中常用于定义常量名称。

全小写 (lowercase)

示例：Hello World -> hello world。将所有英文字母转换为小写。适用于URL、文件名、某些编程场景或统一格式。搜索引擎通常会将查询词转为小写处理。

首字母大写 (Title Case)

示例：hello world -> Hello World。将每个单词的首字母转为大写。适用于文章标题、人名、地名、产品名等需要规范格式的场景。

句首大写 (Sentence Case)

示例：HELLO WORLD. THIS IS A TEST. -> Hello world. This is a test. 只将每个句子的首字母大写，其余保持小写。适用于正文段落、普通句子，是最自然的英文书写格式。

开发者常用命名风格

camelCase 驼峰式

示例：userName, getData。JavaScript变量和函数的常用命名方式。

snake_case 下划线式

示例：user_name, get_data。Python和数据库字段的常用命名方式。

CONSTANT_CASE 常量式

示例：MAX_SIZE, API_KEY。全大写加下划线，用于定义常量和配置项。

转换原理说明

大小写转换的核心原理是利用Unicode字符集中的大小写映射表。每个英文字母在Unicode中都有对应的大写和小写编码，转换工具通过查表替换实现格式转换。

需要注意的是，大小写转换只影响英文字母（A-Z, a-z），中文字符、数字、标点符号等保持不变。多次转换可能导致信息丢失，例如全大写转小写后再转回大写，无法恢复原始的大小写分布。

所有转换都在浏览器本地完成，不会上传任何数据，你可以放心处理包含敏感信息的文本。

常见问题

转换会改变非英文字符吗？

不会。大小写转换只影响英文字母（A-Z, a-z），中文字符、数字、符号等保持不变。

可以转换整篇文章吗？

可以。工具支持大段文本输入，但建议分段处理，以便更好地控制格式和核对结果。

转换后的文本可以撤销吗？

工具会保留原文方便对比。但需注意，多次转换可能无法完全恢复原样，例如全大写转小写后再转大写，原始的大小写分布信息会丢失。

支持哪些命名风格转换？

除了基本的四种大小写转换，还支持camelCase、PascalCase、snake_case、CONSTANT_CASE、kebab-case等编程常用命名风格的互相转换。

转换速度慢怎么办？

对于超大文本（超过10万字），转换可能需要几秒钟。建议将文本分段处理，既能提升速度，也方便核对结果。

我的文本内容安全吗？

安全。所有转换都在浏览器本地完成，不会上传到任何服务器，你的文本内容完全私密。
