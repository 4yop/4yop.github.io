WHOIS域名查询

使用说明

  • 输入域名后点击「查询」按钮，获取域名的完整WHOIS注册信息
  • 支持查询所有主流域名后缀（.com/.cn/.net/.org 等）的WHOIS信息
  • WHOIS信息包含：注册商、注册时间、到期时间、DNS服务器、域名状态等关键数据
  • 部分域名开启了隐私保护，联系人信息可能显示为隐私保护或脱敏处理
  • 查询接口来源：free-api-client (Kit9)，支持 CORS，浏览器端直连查询

WHOIS查询功能详解

WHOIS查询工具可以快速获取任意域名的注册商、注册时间、到期时间、DNS服务器等完整注册信息。无论是购买二手域名前的背景调查、监控自己域名的到期时间、还是分析竞争对手的域名策略，WHOIS信息都是最权威的数据来源。本工具支持所有主流域名后缀（.com/.cn/.net/.org等），输入域名即可一键查看详细信息。

什么是WHOIS查询

WHOIS是一种用于查询域名注册信息的互联网协议和数据库系统。每个域名在注册时都会向域名注册局提交一系列信息，包括注册人姓名、联系方式、注册商、注册日期、到期日期、DNS服务器等。这些信息存储在分布式的WHOIS数据库中，任何人都可以通过WHOIS协议或在线工具进行查询。

WHOIS信息的核心价值在于透明度和可追溯性。对于网站运营者来说，定期检查自己域名的WHOIS信息可以确保联系方式的准确性；对于投资者来说，可以通过WHOIS了解域名的注册历史和价值；对于安全研究人员来说，WHOIS是追踪恶意网站和钓鱼域名的重要线索。

WHOIS信息包含哪些关键字段

一次完整的WHOIS查询通常返回以下关键信息：

基本信息

  • Domain（域名）：被查询的域名本身
  • Registrar（注册商）：域名注册的服务商，如GoDaddy、阿里云、Namecheap等
  • Creation Date（注册时间）：域名首次注册的日期
  • Expiration Date（到期时间）：域名需要续费的最后期限
  • Updated Date（更新时间）：上次修改WHOIS记录的时间

技术信息

  • Name Servers（DNS服务器）：负责域名解析的服务器列表
  • Status（域名状态）：如ok（正常）、clientTransferProhibited（禁止转移）、pendingDelete（待删除）等
  • DNSSEC：是否启用DNS安全扩展

联系人信息（可能受隐私保护）

  • Registrant（注册人）：姓名/组织名称、邮箱、电话、国家/地区
  • Admin（管理员）：技术管理联系人邮箱
  • Tech（技术联系人）：技术支持联系人邮箱
  • Billing（账单联系人）：续费通知接收邮箱

隐私保护说明：自GDPR（欧盟通用数据保护条例）实施以来，许多注册商默认开启WHOIS隐私保护功能，会将注册人的真实个人信息替换为代理服务信息。因此你看到的联系人信息可能显示为"REDACTED FOR PRIVACY"或类似字样。

域名状态代码详解

WHOIS中的Status字段使用标准化的状态码来描述域名的当前状态，理解这些代码对域名管理至关重要：

状态码含义说明
ok正常域名没有任何限制，可正常使用
clientTransferProhibited禁止转移域名被锁定，无法转移到其他注册商（安全措施）
clientDeleteProhibited禁止删除防止误删除域名的重要保护机制
clientUpdateProhibited禁止更新WHOIS信息不可修改
pendingTransfer待转移转移请求已提交，等待确认
pendingDelete待删除域名即将被删除（通常是未续费后的宽限期结束）
inactive非活跃域名已注册但未配置任何DNS服务器
redemptionPeriod赎回期域名过期后30天的赎回期，需支付高额费用恢复

WHOIS查询的常见应用场景

域名投资决策

购买域名前查看其注册历史、年龄、过往持有者等信息，评估域名的真实价值和潜在风险。老域名通常比新域名更有SEO优势。

到期时间监控

定期检查自己名下所有域名的到期时间，设置提前提醒，避免因忘记续费导致域名丢失或进入高价赎回期。

竞品分析

通过WHOIS了解竞争对手域名的注册时间、使用的注册商、DNS服务商等技术选型，为自身决策提供参考。

安全调查

当遭遇网络攻击、钓鱼网站或垃圾邮件时，通过WHOIS查询攻击者域名的注册信息，为溯源取证提供线索。

品牌保护

监控与自己品牌相似或相关的域名注册情况，及时发现抢注行为并采取法律或购买手段保护品牌权益。

网站迁移准备

在更换服务器或DNS服务商前，先确认当前DNS配置和域名状态，避免操作失误导致网站长时间无法访问。

使用WHOIS查询的注意事项

  1. 隐私保护影响数据完整性：由于GDPR等隐私法规的影响，大量域名的联系人信息已被隐藏或脱敏处理，不要指望能查到所有人的真实身份。
  2. 不同后缀的信息格式不同：.com、.cn、.net、.org等不同顶级域的WHOIS返回格式可能存在差异，部分字段可能在某些后缀中不存在。
  3. 数据存在延迟：WHOIS数据库并非实时同步，刚完成的域名注册或修改可能需要几小时甚至几天才能在查询中体现。
  4. 合理控制查询频率：频繁的大量查询可能触发WHOIS服务器的限流机制，建议按需查询而非批量扫描。
  5. 到期时间不等于丢失时间：域名到期后通常有30天左右的续费宽限期，之后还有约30天的赎回期（需额外付费），最后才会被彻底删除释放。
  6. .cn域名有特殊规定：中国管理的.cn域名要求实名认证，WHOIS信息相对更完整准确，但个人注册信息也可能受到保护。

常见问题解答

WHOIS查询是免费的吗？

是的，基本的WHOIS查询是免费的。本站提供的WHOIS查询工具完全免费，无需注册即可使用。部分高级功能（如批量查询、历史记录对比）可能需要付费API服务。

为什么有些域名的联系人信息看不到？

这是正常的。2018年GDPR实施后，大多数域名注册商默认开启了WHOIS隐私保护服务，将注册人的真实姓名、邮箱、电话等信息替换为代理信息或标记为"REDACTED FOR PRIVACY"。这是为了保护个人隐私，符合国际法规要求。

域名快到期了怎么办？

立即登录你的域名注册商账户进行续费。大部分注册商提供自动续费功能，建议开启以避免遗忘。如果已经过了到期日但还在30天内，通常仍可按原价续费；超过30天后会进入赎回期，需要支付较高的赎回费用（通常$80-$200不等）；再往后域名会被公开拍卖或重新开放注册。

如何隐藏自己的WHOIS信息？

大多数主流域名注册商都提供免费的WHOIS隐私保护服务（Whois Privacy / Domain Privacy）。登录你的注册商账户，找到域名管理页面，通常会有"隐私保护"或"WhoisGuard"之类的选项，一键即可开启。开启后，公开的WHOIS信息将显示代理服务的数据而非你的真实信息。

查询结果中status显示多个值是什么意思？

域名可以同时处于多种状态。最常见的组合是"ok + clientTransferProhibited + clientDeleteProhibited + clientUpdateProhibited"，表示域名正常运行且被全面锁定保护（这是推荐的安全配置）。只要不出现"pendingDelete"、"redemptionPeriod"等危险状态，就不用担心。

WHOIS信息和DNS有什么区别？

WHOIS关注的是域名的注册和管理信息（谁拥有、何时注册、何时到期），而DNS（Domain Name System）关注的是域名的解析路由（域名对应哪个IP地址）。简单来说：WHOIS告诉你"这个域名是谁家的"，DNS告诉你"访问这个域名要去哪台服务器"。两者相辅相成，共同构成域名体系的基石。
