DNS解析查询

使用说明

  • 输入域名后选择DNS记录类型，点击「查询」按钮获取DNS解析记录
  • 支持查询多种DNS记录类型：A（IPv4）、AAAA（IPv6）、CNAME（别名）、MX（邮件）、NS（服务器）、TXT（文本）等
  • A记录返回域名的IPv4地址，AAAA记录返回IPv6地址
  • CNAME记录用于域名别名指向，MX记录指定邮件服务器
  • NS记录显示域名的DNS服务器，TXT记录常用于SPF、DKIM等验证
  • 查询接口来源：Google Public DNS (dns.google)，通过 HTTPS JSON API 查询，无跨域问题
