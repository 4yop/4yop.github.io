在线提词器 - 视频录制文字滚动工具

在线提词器是一款专为视频录制、直播和演讲设计的文字滚动工具。输入或粘贴文本后，点击开始即可自动滚动显示，支持调节滚动速度和字体大小，提供正常、镜像和倒置三种显示模式，还可以进入全屏模式获得最佳提词效果。所有内容自动保存到浏览器本地。

下面介绍如何使用在线提词器提升录制和演讲效果，以及提词器的工作原理。

什么是提词器

提词器（Teleprompter）是一种在演讲、录制或直播时辅助朗读的工具，通过屏幕滚动显示讲稿文字，让演讲者无需低头看稿即可流畅表达。专业提词器通常使用透明玻璃反射文字，演讲者可以直视镜头同时看到讲稿内容。在线提词器将这一功能搬到浏览器中，无需额外硬件即可使用。

核心功能

三种显示模式

正常、镜像和倒置模式适配不同场景

速度调节

1-10 级滚动速度，匹配不同语速

自动保存

文本和配置自动保存到浏览器本地

使用教程

  1. 在文本区域输入或粘贴需要提词的内容，支持多段文本。
  2. 根据语速调整滚动速度（1-10 级），建议先从 5 级开始试读再微调。
  3. 如果用提词器支架配合摄像头，选择"镜像"模式让文字在反射后正常显示。
  4. 录制前先完整试读一遍，确认速度和字体大小合适后再正式开始。

适用场景

  • 视频录制，对着镜头流畅朗读脚本
  • 直播带货，滚动展示商品介绍和话术
  • 在线演讲，远程会议时辅助发言
  • 课堂录制，教师按讲稿录制课程视频

技术原理

本工具通过 CSS transform 实现文字的镜像和倒置效果，通过 JavaScript 定时器控制文字的自动滚动速度。全屏模式使用 Fullscreen API 实现。文本内容和配置参数通过 localStorage 自动持久化，确保关闭页面后数据不丢失。快捷键通过键盘事件监听实现，支持空格暂停、方向键调速等操作。

常见问题

镜像模式是什么？

镜像模式会将文字水平翻转，配合提词器支架使用时，文字通过玻璃反射后恢复为正常方向，方便对着摄像头朗读。

支持快捷键操作吗？

支持，空格键开始/暂停，上下箭头调节字体大小，左右箭头调节速度，ESC 复位，F11 全屏。

内容会丢失吗？

不会，文本内容和配置参数会自动保存到浏览器本地存储，关闭页面后重新打开仍可恢复。

可以调节字体大小吗？

可以，通过上下箭头键或界面控件调节字体大小，适配不同屏幕和视距。

手机上可以使用吗？

可以，工具已适配移动端操作，支持触屏控制滚动和暂停。

支持多长的文本？

没有硬性长度限制，数千字的讲稿都能正常滚动显示。建议分段输入，便于调试速度。
