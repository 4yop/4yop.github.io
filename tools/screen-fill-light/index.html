屏幕补光灯 - 在线柔光补光工具

屏幕补光灯是一款利用屏幕发光为面部提供补充光源的在线工具。将屏幕调整为均匀的暖色或冷色光面，放在面部前方即可柔和地照亮你的脸，起到和专业补光灯类似的效果。支持色温调节、亮度控制、呼吸灯效果和全屏模式，无需购买额外设备。

下面介绍如何使用屏幕补光灯提升视频通话和自拍效果，以及补光的基本技巧。

什么是屏幕补光灯

屏幕补光灯的原理很简单：将屏幕调整为均匀的暖色或冷色光面，放在面部前方，屏幕发出的光线就能柔和地照亮你的脸。与传统的硬件补光灯相比，屏幕补光灯不需要额外购买设备，打开浏览器就能使用，特别适合临时需要补光但又没有专业器材的场景。

核心功能

色温调节

1000K-15000K，从烛光色到日光色自由切换

亮度控制

无级调节屏幕亮度，适配不同环境

呼吸灯效果

屏幕亮度随节奏缓慢起伏，营造氛围

使用教程

  1. 打开屏幕补光灯工具页面，根据需要调节色温滑块，一般视频通话建议 4000K-5500K。
  2. 调整亮度滑块，让光线强度适中，太亮容易过曝，太暗则补光效果不明显。
  3. 如需调整色彩浓度，可以微调饱和度参数。
  4. 点击全屏按钮，让屏幕变为纯净的光源面，将设备放在面部前方偏上位置使用。

适用场景

  • 视频通话，线上会议和远程面试时面部补光
  • 直播，夜间或光线不足时用另一台设备补光
  • 自拍，用另一台手机屏幕补光告别暗沉
  • 阅读灯，夜间将屏幕调至暖色低亮度当小夜灯

技术原理

本工具通过 CSS 色温算法将开尔文色温值转换为 RGB 颜色，使用 HSL 色彩空间实现亮度和饱和度的独立控制。呼吸灯效果通过 CSS animation 或 requestAnimationFrame 实现亮度的正弦波周期变化。全屏模式使用 Fullscreen API 最大化补光面积，消除浏览器界面元素的干扰。

常见问题

屏幕补光效果和真实补光灯一样吗？

屏幕补光面积大、光线柔和，适合应急使用，但亮度和色温精度不如专业补光灯，长期使用建议搭配专业设备。

长时间使用会伤眼吗？

建议将补光设备放在侧面或偏离视线的位置，避免直视高亮屏幕。使用暖色温（3000K-4000K）对眼睛更友好。

手机屏幕可以当补光灯吗？

可以，在手机浏览器中打开本工具即可使用，手机屏幕补光建议距离面部 30-50 厘米。

色温怎么选？

日常视频通话选 4000K-5500K 最自然；直播或自拍可以试试 3000K-4000K 的暖光，显得肤色更好。

双屏补光效果更好吗？

是的，如果有两块屏幕，分别放在左右两侧 45 度角，能获得更均匀的环形光效果。

呼吸灯效果有什么用？

呼吸灯适合冥想、放松或创意拍摄场景，模拟自然光线变化，营造独特氛围。
