网站巡检器 - 登录保活助手，一键批量打开网站让你自己检查登录状态

网站巡检器是一款纯辅助工具——它只负责帮你按顺序批量打开多个常用网站的标签页，登录状态需要你自己肉眼检查。 支持自定义网站列表、巡检间隔时间、一键启停控制，所有数据保存在浏览器本地，无需注册完全免费。

⚠️ 重要说明：本工具不会替你检查登录状态，也不会自动读取 Cookie 或自动登录。工具只是帮你省掉逐个点击、逐个输入网址的麻烦，真正查看"是否已登录"的永远是你自己。

每天上班第一件事就是检查各个后台系统是否还在登录状态？用这个工具一键打开所有站点，你只需要看一眼页面是否已登录，省去逐个输入网址的麻烦。

功能介绍

网站管理

添加、编辑、删除网站，拖拽排序，启用/禁用控制

一键打开网站

按序逐个打开网站标签页，你自己检查登录状态，可配置间隔时间，随时停止

数据管理

导入导出 CSV 配置，数据保存在浏览器本地

如何使用网站巡检器

  1. 添加网站：在输入框中填写网站名称和网址，点击"添加"按钮，支持 HTTP 和 HTTPS 协议。
  2. 管理列表：通过拖拽调整顺序，用开关控制是否参与巡检，点击编辑或删除按钮修改网站信息。
  3. 设置间隔：调整打开网站的时间间隔（1-60秒），给足你自己查看和判断的时间。
  4. 开始巡检：点击"开始巡检"按钮，工具将按列表顺序使用 window.open 逐个打开网站标签页——然后由你自己肉眼检查每个页面是否已登录。
  5. 查看进度：面板实时显示当前打开的序号、网站名称和下一站目标，进度条直观展示完成比例。
  6. 停止控制：如果已经检查完，点击"停止巡检"即可清除定时器，不会继续打开后续网站。
  7. 巡检日志：每次打开操作都会记录时间戳和网站名称，方便追溯检查过程。
  8. 备份迁移：使用导出功能保存网站列表为 CSV 文件，在其他设备上导入即可恢复配置。

隐私与安全说明

本工具纯前端运行，所有网站配置和日志数据仅保存在浏览器的 LocalStorage 中，不会上传到任何服务器。 工具仅通过 window.open 打开网站，不会读取 Cookie、不会自动登录、不会替你检查任何内容。 各网站打开后需由你本人自行输入账号密码或使用已保存的凭据登录，完全由你自己控制，符合浏览器安全规范。

常见问题

网站巡检器能自动登录或自动检查吗？
不能。本工具仅通过 window.open 打开网站标签页，检查登录状态这件事必须由你自己完成。工具不会读取 Cookie、不会注入密码、不会自动判断你是否已登录。它是纯辅助工具，帮你省掉逐个打开标签页的体力活，真正的"检查"动作永远是你自己。
为什么有些网站没有打开？
浏览器的弹窗拦截机制可能会阻止 window.open。请确保允许本网站的弹窗权限，或检查浏览器地址栏右侧是否有弹窗拦截提示。此外，部分网站可能设置了反爬或安全策略，拒绝通过脚本打开的窗口。
数据保存在哪里？会丢失吗？
所有数据保存在浏览器 LocalStorage 中，关闭页面后重新打开仍然存在。但如果清除浏览器缓存或使用隐私模式，数据可能会丢失。建议定期导出 CSV 文件备份。
间隔时间设置多少合适？
建议设置在 3-5 秒之间，给足你自己查看和判断的时间。间隔太短你可能来不及检查，间隔太长则效率较低。如果网站加载速度较慢，可适当增加间隔时间。

本工具数据全部保存在本地浏览器中，不会上传至任何服务器。工具仅帮你打开网站，检查登录状态永远是你自己的事。
