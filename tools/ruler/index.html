在线尺子 - 屏幕测量工具

在线尺子是一款实用的屏幕测量工具，利用 Canvas 技术在浏览器中渲染高精度刻度尺。支持厘米和英寸两种单位切换，提供横向和纵向两种显示方向，还可以进入全屏模式获得更大的测量区域。无需下载安装，打开网页即可使用。

下面介绍如何使用在线尺子进行屏幕测量，以及屏幕尺子的精度原理。

屏幕尺子的原理

屏幕尺子通过获取显示器的 DPI（每英寸点数）参数，将像素单位换算为物理长度单位（厘米或英寸），从而在屏幕上渲染出与真实尺子刻度一致的标尺。标准显示器通常为 96 DPI，高分辨率屏幕（如 Retina）DPI 更高，工具会自动适配以确保刻度准确。

核心功能

双单位切换

支持厘米和英寸两种测量单位

双方向显示

提供横向和纵向两种显示方向

全屏测量

进入全屏模式获得更大测量区域

使用教程

  1. 选择测量单位（厘米或英寸），根据需要切换横向或纵向模式。
  2. 将待测物体贴近屏幕边缘，对齐零刻度线。
  3. 读取物体末端对应的刻度值，获得长度数据。
  4. 如需更大显示区域，点击"全屏测量"进入全屏模式，按 ESC 退出。

适用场景

  • 日常物品尺寸估算，手边没有尺子时应急使用
  • 手工制作测量，快速确认零件或材料尺寸
  • 屏幕尺寸对比，比较不同设备的显示区域
  • 教学演示，在课堂上展示测量方法

技术原理

本工具使用 Canvas API 绘制刻度线和数字标注。通过 window.devicePixelRatio 获取设备像素比，结合 screen DPI 计算出像素与物理长度的换算系数。刻度线采用亚像素渲染技术，在高 DPI 屏幕上也能保持清晰锐利。用户偏好通过 localStorage 持久化存储。

常见问题

测量结果准确吗？

准确度取决于屏幕的 DPI 设置，标准 96 DPI 屏幕下误差较小。如需高精度测量，建议使用实物尺子校准。

为什么刻度看起来模糊？

工具已针对高分辨率屏幕优化，如果仍然模糊，请检查浏览器的缩放比例是否为 100%。

设置会保存吗？

会，你的单位和方向偏好会自动保存到浏览器本地，下次打开时自动恢复。

手机上测量准确吗？

手机屏幕 DPI 通常较高且较为统一，测量精度一般优于电脑显示器，但仍建议以实物尺子为准。

可以校准尺子吗？

目前使用系统 DPI 自动计算，如需校准可以在系统显示设置中调整缩放比例来间接校准。

最长可以测量多少？

测量范围取决于屏幕尺寸，全屏模式下可覆盖整个屏幕宽度或高度，通常 13-27 英寸屏幕可测量 30-70 厘米。
