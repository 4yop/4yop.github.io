二次元人格原型测试（ACGTI，即 ACG Type Indicator）是基于 MBTI 经典四维模型延伸的二次元向人格测评工具。通过 39 道情境式问题，从精力导向、认知模式、决策逻辑、生活态度和人际依附五大维度分析你的性格特征，匹配到唯一的二次元角色原型代码。测试结果会揭示你在二次元世界中的灵魂角色，帮助你更好地理解自己的性格倾向和行为模式。

这个二次元人格原型测试完全免费、无需注册，打开浏览器即可开始。所有测试数据在本地处理，不会上传到服务器，保护你的隐私。适合动漫爱好者、二次元文化粉丝和性格测试爱好者。

二次元人格原型的八大分类

测试基于ACGTI五大维度框架（精力导向A / 认知模式C / 决策逻辑G / 生活态度T / 人际依附I），将二次元人格分为八种专属原型：

  • 发光主角位：高表达、强推进，天生带领团队冲锋的气氛引擎，注定站在聚光灯下。
  • 冰面观察者：低调清醒的"高侦察"面板，习惯先看透规则底线再决定是否下场，残局里最稳的兜底人。
  • 誓约队长：高守序、强支柱，团队里最扎实的承重墙，能在高压下顶住一切，关键时刻永不退缩。
  • 灵巧回旋者：高机动、多变阵，对僵局极其敏感，擅长用不按套路出牌的方式制造翻盘神迹。
  • 温柔修复者：高治愈、强辅助，对人际关系中的情绪变化极其敏锐，永远是队伍里默默给队友提供情绪价值的灵魂树洞。
  • 影面策士：满级"战术预判"的幕后黑手位，习惯在暗处拆解复杂局势，从不轻易亮出底牌，出手即翻盘。
  • 混沌火花：点满"高风险、强爆点"的变局面板，讨厌一眼望到头的剧本，常常用最出人意料的方式点燃平淡的局面。
  • 月下守护者：安静站在边界上的人，外表疏离内心却比谁都认真，不喧哗但永远在场。

常见问题

ACGTI测试和传统MBTI测试有什么区别？

ACGTI在MBTI四维模型（E/I、S/N、T/F、J/P）基础上新增了"人际依附"维度（独立I/协作W），将16型MBTI扩展为32型人格类型。不同于传统MBTI用职业标签描述性格，ACGTI用八种二次元角色原型（发光主角位、冰面观察者、誓约队长等）来诠释人格特征，更适合ACG文化爱好者理解和共鸣。

ACGTI测试结果中的角色代码是什么意思？

角色代码由五大维度的倾向字母组成，格式为"ACGTI"。其中A代表精力导向（外向/内向）、C代表认知模式（实感/直觉）、G代表决策逻辑（理性/感性）、T代表生活态度（判断/感知）、I代表人际依附（独立/协作）。系统根据你的得分自动计算代码并匹配对应的角色原型。

二次元人格测试适合哪些人使用？

适合动漫爱好者、二次元文化粉丝、MBTI爱好者以及任何想通过有趣方式了解自己性格的人。也适合学生社团活动、朋友聚会等社交场景互动使用，和好友一起测试对比各自的二次元人格类型。

测试结果准确吗？

本测试基于性格分析理论设计，结果仅供参考和娱乐，不构成专业心理评估。如果需要专业的性格分析，建议咨询心理咨询师。

ACGTI测试可以重复测试吗？

可以，每次测试的题目顺序可能不同，但如果你诚实作答，结果通常是一致的。每次ACGTI测试结果都会保存到历史记录，方便随时回顾。

ACGTI测试需要多长时间？

39 道题目通常需要 5-10 分钟完成，建议在不受打扰的环境下一次性完成ACGTI测试以获得最准确的结果。
