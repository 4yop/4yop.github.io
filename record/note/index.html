如何使用在线便签工具？

  1. 新建便签：点击任意便签左上角的"+"号，即可在它前面添加一张新便签。
  2. 编辑内容：直接点击便签的空白区域，就可以开始打字记录。底部工具栏支持加粗、斜体、下划线、删除线和项目符号列表。
  3. 插入图片：点击便签底部的图片按钮，从电脑中选择一张图片插入。插入后点击图片可放大查看，左右切换浏览其他图片，点击空白处关闭大图。
  4. 改变颜色：点击便签右上角的"..."按钮，弹出一排颜色选项，点一下就能给便签换背景色，方便分类。
  5. 调整顺序：点击便签右上角的箭头按钮，可以将便签向前或向后移动位置。
  6. 删除便签：点击便签右上角的关闭按钮，确认后即可删除。
  7. 导出备份：点击页面上方的"导出"按钮，下载包含所有便签文字和图片的压缩包文件。
  8. 导入恢复：点击"追加导入"将备份内容添加到现有便签后面，或点击"覆盖导入"用备份完全替换当前所有便签。

在线便签工具的工作原理是什么？

本工具基于浏览器本地存储与富文本编辑技术实现，核心工作流程如下：

  • 使用浏览器的 IndexedDB 存储所有便签数据，包括文字内容、颜色、排列顺序和图片引用
  • 图片以 Base64 编码方式存储在本地，确保离线状态下也能正常显示
  • 富文本编辑基于 contentEditable API 实现，支持加粗、斜体、下划线、删除线和列表等格式
  • 导出功能将所有便签数据和图片打包为压缩包文件下载，导入功能解析压缩包并还原便签
  • 响应式布局自动适配手机和电脑屏幕，确保在不同设备上都有良好的使用体验

注：本工具的数据全部保存在本地浏览器中，不会上传至任何服务器。清空浏览器缓存会导致数据丢失，建议定期导出备份。

常见问题

在线便签工具是免费的吗？需要注册吗？

是的，本工具完全免费，无需下载安装，在浏览器中打开即可使用。同时不需要注册任何账号，所有数据保存在你自己的设备浏览器中，不会上传到任何服务器，保护你的隐私安全。

关闭浏览器后便签内容会丢失吗？

不会。本工具使用浏览器的本地存储（IndexedDB）自动保存所有便签数据，包括文字、图片、颜色和排列顺序。关闭页面后重新打开，内容依然完整保留。但请注意，如果清空浏览器缓存，数据会被删除，建议定期导出备份。

便签中插入的图片有大小限制吗？

本工具不限制插入图片的大小，你可以插入任意尺寸的图片。插入后点击图片可以放大查看全貌，在大图浏览模式下还可以左右切换查看其他图片，点击空白处或黑色背景即可关闭大图。

追加导入和覆盖导入有什么区别？

追加导入会将备份文件中的便签添加到当前所有便签的后面，原有便签不受影响，适合合并不同设备上的笔记。覆盖导入会用备份文件完全替换当前所有便签，适合从备份中完整恢复数据。操作前请确认选择正确的导入方式。

便签的颜色有哪些选项？怎么切换？

本工具提供多种背景颜色选项，包括常见的米黄色、粉色、绿色、蓝色等。点击便签右上角的"..."按钮，会弹出一排颜色选项，点一下就能给便签换背景色。你可以用不同颜色来区分不同类别的便签，比如红色代表紧急、绿色代表已完成。

手机上使用方便吗？

本工具针对移动端进行了专门优化，界面会根据屏幕大小自动调整布局。在手机上可以正常新建、编辑、删除便签，插入图片和切换颜色等操作也都支持。不过由于手机屏幕较小，建议在电脑上进行大量文字编辑操作会更高效。

清空便签功能会直接删除所有内容吗？

不会直接删除。点击"清空"按钮后，页面会弹出明确的确认提示，只有在你确认后才会执行清空操作，避免误删。如果你不小心清空了便签，只要之前做过导出备份，就可以通过"覆盖导入"来恢复所有内容。

本工具的数据全部保存在本地浏览器中，不会上传至任何服务器。清空浏览器缓存会导致数据丢失，建议定期导出备份。
