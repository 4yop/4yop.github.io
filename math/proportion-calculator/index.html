在线比例计算器帮你快速求解比例等式中的未知数。只需输入 A:B = C:D 中的任意三个值，工具会自动计算出第四个值。同时提供常用快捷比例（如 1:2、3:4、16:9 等），方便在缩放图片、调整配方、换算单位等场景中使用。

下面介绍如何使用比例计算器快速求解比例等式。

什么是比例计算

比例是数学中表示两个比相等的关系，记作 A:B = C:D。其中 A 和 D 称为外项，B 和 C 称为内项，比例的基本性质是外项之积等于内项之积（A x D = B x C）。利用这个性质，只要知道三个值就可以求出第四个未知值。比例计算广泛应用于缩放、配方调整、地图比例尺、货币换算等日常生活场景。

核心功能

自动求解

输入三个值自动计算第四个未知数

快捷比例

使用教程

  1. 在 A:B = C:D 的四个输入框中填入已知值，留空一个作为未知数。
  2. 点击计算按钮，工具会自动求解未知数并显示结果。
  3. 如果需要常用比例，点击快捷比例按钮直接填入。
  4. 按 ESC 键可以清空所有输入，重新开始计算。

适用场景

  • 图片缩放：按比例调整图片尺寸，保持宽高比不变
  • 配方调整：按比例增减食材用量，保持口感一致
  • 单位换算：利用比例关系进行不同单位间的换算
  • 地图计算：根据比例尺换算实际距离

计算原理

比例等式 A:B = C:D 的核心性质是交叉相乘相等：A x D = B x C。当需要求解未知数时，只需将已知三个值代入公式即可。例如已知 A、B、C 求 D，则 D = B x C / A。工具在内部实现了这一逻辑，并处理了除零错误和精度问题，确保计算结果准确可靠。

常见问题

可以留空多个值吗？

不可以，必须输入三个已知值，只能留空一个未知数，否则无法计算。

支持小数和负数吗？

支持小数，但不建议使用负数，因为比例通常表示正数之间的关系。

计算精度如何？

结果保留合理的小数位数，日常使用精度足够，满足绝大多数场景需求。

16:9 和 4:3 有什么区别？

16:9 是宽屏比例，适合视频和现代显示器；4:3 是传统屏幕比例，适合老式显示器和照片。

比例和比率是一回事吗？

不完全相同。比率通常指两个数的商（如 3/2=1.5），而比例是两个比相等的等式（如 3:2=6:4）。

快捷比例可以自定义吗？

目前内置了常用快捷比例，后续版本会考虑增加自定义快捷比例的功能。
