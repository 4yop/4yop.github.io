贷款计算器 - 房贷车贷月供利息在线计算工具

贷款计算器支持等额本息和等额本金两种还款方式的月供、总利息和还款总额计算，并列出前 12 期还款明细。适合房贷估算、车贷计算、消费贷规划等场景，帮你快速比较不同方案的还款压力和总成本。

下面介绍两种还款方式的区别和计算器的使用方法。

等额本息与等额本金的区别

等额本息每月还款金额固定，前期利息占比大、本金占比小，适合收入稳定的人群。等额本金每月还的本金固定，利息逐月递减，前期月供较高但总利息更少，适合前期还款能力较强的人。选择哪种方式取决于你的现金流和长期规划。

使用教程

  1. 输入贷款金额，尽量按真实准备贷的金额填写。
  2. 输入年利率，先用银行给到的口径，不要混用宣传利率和审批利率。
  3. 选择贷款年限，不同年限直接影响月供压力和总利息。
  4. 选择还款方式（等额本息或等额本金），查看计算结果和还款明细。

适用场景

  • 房贷估算：买房前估算月供，评估还款能力
  • 车贷计算：比较不同车贷方案的月供和总利息
  • 消费贷规划：评估分期付款的真实成本
  • 提前还款决策：对比提前还款前后的利息差异

计算原理

等额本息月供公式：M = P x r x (1+r)^n / ((1+r)^n - 1)，其中 P 为贷款本金，r 为月利率，n 为还款期数。等额本金每月本金 = P / n，每月利息 = 剩余本金 x r，因此月供逐月递减。工具按标准口径计算，结果仅供预算参考。

常见问题

为什么结果和银行方案不完全一样？

银行审批会叠加实际利率、手续费、组合贷结构和还款规则，工具只做标准口径试算，结果供预算参考。

该先看月供还是总利息？

如果更关心每月压力，先看月供；如果在比长期成本，再看总利息和总还款额。两者结合才能做出最佳决策。

能替代正式贷款方案吗？

不能，结果仅供预算参考，最终以银行审批和合同为准。建议在正式申请前用工具做初步估算。

等额本息和等额本金哪个更划算？

从总利息看，等额本金更划算。但等额本金前期月供较高，需要根据你的现金流选择适合的方式。

贷款年限怎么选？

年限越长月供越低但总利息越多，年限越短月供越高但总利息越少。建议选择月供不超过月收入 50% 的年限。

提前还款划算吗？

如果贷款利率高于你的投资收益率，提前还款通常划算。但要注意银行可能收取提前还款违约金，需综合考虑。
