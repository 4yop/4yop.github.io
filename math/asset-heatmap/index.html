资产分布热力图 — Treemap 持仓结构可视化工具详解

资产分布热力图是一个将多币种持仓数据转化为可视化 treemap 的在线工具。本文介绍它的核心功能、使用场景和实际操作方法。

什么是资产分布热力图？

资产分布热力图（Asset Heatmap）采用矩形树图（Treemap）布局，将每项持仓显示为一个矩形方块。方块面积 = 折算市值（数量 × 当前价 × 汇率），面积越大代表该项资产占组合的比重越高。颜色 = 币种，不同币种使用不同色系，方便一眼看清整体币种结构。

与传统的饼图相比，Treemap 可以在有限空间内展示更多层级信息，同时避免饼图在类别过多时的视觉混乱。每项资产在图中清晰可见，悬停即可查看原币市值、折算市值和占比百分比。

核心功能

多币种自动折算

支持人民币、美元、港币、日元、欧元、英镑、新加坡元、澳元 8 种货币，通过 Frankfurter 开源 API（欧洲央行数据源）获取实时汇率，将所有持仓折算到同一基准币种。

标签分类视图

给每项持仓打上自定义标签（如科技、消费、蓝筹、新能源），可切换「按标签」视图将同标签资产归并显示，快速了解各类别占比。

隐私保护模式

开启隐私模式后，所有金额数字替换为「*****」，仅保留面积占比结构。适合在公开场合展示或不希望暴露具体金额时使用。

离线可用

汇率数据自动缓存到浏览器本地，断网时使用上次缓存的汇率渲染热力图，状态栏标注「离线汇率」提醒。你的持仓数据保存在 localStorage，不上传服务器。

使用场景

  • 跨市场持仓一图看穿 — 同时持有多市场资产（A 股、港股、美股、基金、ETF 等），把所有持仓换算成同一币种后按市值面积摆一起，谁是大头一眼分明。
  • 币种集中度自检 — 颜色按币种分块，直观看出是否大部分仓位都压在单一币种资产上，决定是否需要分散汇率风险。
  • 月度配置快照 — 每月更新一次当前价，对比上月截图看资产结构变化，做仓位再平衡时不靠记忆。
  • 自定义标签 + 板块视图 — 给持仓打上消费/科技/新能源等标签，切换按标签视图把同类持仓合并为一块，看行业集中度。

使用方法

  1. 在「持仓明细」表格中逐行输入资产名称、数量、当前价，选择币种。可选填标签（用逗号分隔多个标签）。
  2. 从顶部下拉框选择基准币种，工具会自动从 Frankfurter API 获取最新汇率进行折算。
  3. 热力图区域实时渲染，鼠标悬停方块查看详细数据（原币市值、折算市值、占比）。
  4. 点击「按标签」切换到标签聚合视图，相同标签的持仓合并显示。
  5. 点击「合并小仓位」将占比小于 1% 的项合并为「其他」显示，让大头更清晰。
  6. 点击导出按钮（下载图标）将热力图保存为 PNG 图片。
  7. 从 Excel 或 Google Sheets 复制数据后，点击「粘贴导入」一键批量添加持仓。

常见问题

面积和颜色各代表什么？

面积 = 折算到基准币种的市值（数量 × 当前价 × 汇率），方块越大说明该项持仓占比越高。颜色 = 币种，每种货币一种颜色，方便一眼看出资产结构。悬停可查看原币市值、折算市值和占比百分比。

汇率从哪里获取？准确吗？

汇率通过 Frankfurter 开源 API 获取，数据源为欧洲央行（ECB），每个工作日更新一次，对个人资产配置估算精度足够。注：ECB 不发布周末汇率，周六日显示周五数据。

数据安全吗？会上传服务器吗？

你的持仓数据保存在浏览器本地 localStorage 中，不上传服务器。本站是纯静态站点，没有后端、没有账户系统。清浏览器缓存会丢失数据，建议重要数据另外备份。

为什么有的方块没有文字？

ECharts treemap 会在方块面积太小时自动隐藏标签，避免文字溢出。这通常意味着该持仓占比小于 1%，悬停依然可以看到详情。建议合并同类持仓或只展示权重大于 0.5% 的项目。

注意事项

  • 本工具仅做输入数据到可视化呈现的纯计算与渲染，不抓取行情、不预测涨跌、不推荐标的。
  • 展示结果不构成任何形式的投资建议或承诺，请基于自身判断和专业意见做决策。
  • 汇率数据仅供参考，实际交易请以银行或券商实时报价为准。
  • 建议每月更新一次价格即可——看的是配置结构，不是 K 线波动。
