时薪是衡量工作价值的基准指标。了解自己的时薪有助于：在薪资谈判时评估报价是否合理，在自由职业时合理定价服务，在日常决策时判断某件事是否值得花时间做。将月薪换算为每秒收入，更能直观感受时间的金钱价值，从而更珍惜时间。很多人只看月薪数字，却忽略了实际工作时长对真实时薪的影响。

计算原理

核心公式为：时薪 = 月工资 / (上班天数 x 每日工时)。得出时薪后，其他维度按时间换算即可：每分钟收入 = 时薪 / 60，每秒收入 = 时薪 / 3600，每日收入 = 时薪 x 每日工时，每月收入即输入的月工资。工具通过定时器每秒更新一次显示数值，模拟收入实时增长的效果。

常见问题

计算公式是什么？

时薪 = 月工资 / (上班天数 x 每日工时)，其他维度按时薪换算。每秒收入 = 时薪 / 3600。

包含五险一金和税吗？

不包含，输入的是税前工资，实际到手金额需自行扣除五险一金和个人所得税。

可以计算年薪吗？

可以，月工资乘以12即为年薪，也可以直接输入年薪除以12换算为月工资后使用。

加班时间怎么算？

可以将每日工时设为包含加班的总工时，这样算出来的时薪更接近真实水平。

为什么暂停后数字不再变化？

暂停功能是为了方便你仔细查看当前各维度的收入数据，恢复后数字会继续实时跳动。

这个工具适合自由职业者吗？

非常适合。自由职业者可以输入目标月收入和预计工作时长，反推每小时和每秒应赚多少，帮助合理定价服务。
