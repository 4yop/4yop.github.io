税金税率计算器 - 含税价未税价在线换算工具

税金税率计算器支持含税价与未税价的互相换算，以及从含税价和未税价反推税率。涵盖增值税常见税率（13%、9%、6%等），同时显示税额和中文大写金额，方便财务做账。适合开发票、财务报销、合同签订等场景。

下面介绍含税价、未税价和税率的关系，以及如何使用计算器。

含税价、未税价和税率的关系

未税价是商品本身的价格，不包括税款。税率即税点，如常见的 13%、9%、6%等，不同行业不同商品税率可能不同。含税价是商品价格加上税款后的总价，也就是你最终支付的金额。三者关系：含税价 = 未税价 x (1 + 税率)。理解这个公式，就能轻松应对各种税务计算场景。

三种计算模式

未税价算含税价

输入未税金额和税点，得出含税总价和税额

含税价算未税价

输入含税总价和税点，反推未税金额和税额

反推税率

输入含税价和未税价，计算实际税率

使用教程

  1. 选择计算模式：从未税价算含税价、从含税价算未税价、或反推税率。
  2. 输入已知数值，如未税金额 100 元，税点 13%。
  3. 点击计算，立即显示含税金额、税额等结果，同时提供中文大写金额。
  4. 可以一键复制结果，方便粘贴到发票或报销单中。

适用场景

  • 开发票：快速计算含税金额，填写发票信息
  • 财务报销：从含税金额反推未税金额，核对报销单据
  • 合同签订：明确含税价和未税价，避免纠纷
  • 采购比价：统一换算为未税价进行公平比较

计算原理

三种计算模式的核心公式：含税价 = 未税价 x (1 + 税率)，未税价 = 含税价 / (1 + 税率)，税率 = (含税价 - 未税价) / 未税价 x 100%。例如未税价 100 元，税率 13%，含税价 = 100 x 1.13 = 113 元，税额 = 113 - 100 = 13 元。工具同时将结果转换为中文大写金额，符合财务规范。

常见问题

常见的增值税税率有哪些？

中国增值税常见税率：13%（一般货物和劳务）、9%（交通运输、建筑等）、6%（金融服务、现代服务等）、3%（小规模纳税人征收率）。

含税价和未税价哪个更常用？

日常消费看到的多是含税价，而企业财务和发票上通常需要分别列明未税价、税额和含税价。

中文大写金额有什么用？

中文大写金额难以涂改，是财务票据的规范要求。工具自动将数字转换为大写金额，方便填写发票、收据和合同。

税点可以输入小数吗？

可以，税点支持小数输入，如 0.5%、1.5% 等，满足特殊行业的税率需求。

计算结果和银行发票有差异怎么办？

可能是因为银行或开票系统使用了不同的四舍五入规则。本工具按标准数学计算，结果供参考，实际以银行或税务系统为准。

这个工具能算个人所得税吗？

本工具专门计算含税价/未税价的换算，个人所得税计算请使用个税计算器。
